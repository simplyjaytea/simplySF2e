# Item Forge and generator audit — 2026-09-05

Branch: `codex/forge-generator-audit`, based on `b043a51` (PR #103, published v0.3.5.63). This audit covers the forge, NPC/monster/encounter creation, supported PC creation, shared provider boundaries, and their regression suite. It does not certify every PF2e rule or unsupported class.

## Changes

| Area | Confirmed defect | Result |
| --- | --- | --- |
| Forge layout | Native fixed button height clipped the type hints into the next label | Tiles grow with their contents and wrap at narrow widths |
| Forge lifecycle | Repeated Generate could overlap; cancellation during final assembly could publish a draft; sheet failure left a saved item retryable | One active run, final cancellation check, committed draft consumed before presentation |
| Forge effects | AI could supply extreme bonuses/dice/DCs; a generic rule shape did not establish a valid magnitude | Exact eligible published passive rules, scale/enum choices, module-owned activation values |
| Forge catalog | Artifact/prerequisite sources and unsupported selectors could enter offered choices | Detected source restrictions and supported targets are screened before offering |
| Activation copies | Removing one copy could delete a shared macro; only GM rest recharged | Last-reference cleanup and initiating-owner recharge |
| Activation charges | Failed writes could still apply an effect; double clicks and second copies were mishandled | Persisted-counter checks, same-client in-flight guard, available-copy selection |
| Loot reroll | Failure discarded the old manifest; fuzzy matching could re-enter the exact pipeline | Atomic replacement, exact references, completeness before commit |
| Prompt fidelity | Refinements lost the original GM request; empty loot was repopulated with coins | Original brief retained, prompt gives explicit constraints priority, valid empty drafts survive |
| Equipment | Ammunition was filtered out, quantity one retained source packs of ten, pack prices were treated as unit prices | Native ammo accepted, selected quantities written, `price.per` respected |
| Assembly | A selected source disappearing after preview could silently become custom or vanish | Stop before native creation when the selected source is unavailable |
| Encounters | Fixed bosses exceeded small-party budgets; Low-threat adjustment was 15 instead of 20 XP | Budget-bounded composition and clear pre-provider error for impossible tiny budgets |
| NPC skills | Perception could be written as a second skill with a conflicting value | Perception remains owned by the perception benchmark |
| PC loadout | Cloaks/backpacks were treated as armor and stowed | Armor proficiency/slot checks apply only to armor |
| PC feats | Generic cadence omitted first-level class feats and accelerated skill feats | Native class schedules supply all slots; prerequisites evaluated at the earned level |

Investigator's restricted odd-level Skillful Lessons slots admit only proven explicit mental-skill/Lore prerequisites. Generic choices and unmodeled methodology exceptions remain excluded rather than guessed.

## Local verification of the revised branch

The actual forge Handlebars template and branch CSS were rendered against the test server's native Foundry CSS in a temporary local fixture. At **360, 480, and 720px** form widths all type-copy bounds fit inside their tiles and the form body had no horizontal overflow. This validates the layout fix, not ApplicationV2 lifecycle or PF2e derived data. The fixture intentionally did not reproduce Foundry's complete loaded font/icon environment.

Baseline: **69 regression files**, **104 script syntax checks**, module/localization JSON and whitespace checks passed. New tests exercise production helpers/classes/requests with stubbed platform/transport, including failures reproduced before fixes. Final suite results and independent-review outcome are recorded in HANDOFF.md.

Source checks fetched `foundryvtt/pf2e/master` as required. Master currently identifies as the older 6.12.4 line, so changes depending on installed-era shapes also used **pf2e-8.5.0**:

- Class document: `grantedFeatSlots` reads the real ancestry/class/skill/general schedules.
- Skillful Lessons: published description restricts odd-level feats to mental skills or the methodology skill.
- Arrows: `type: "ammo"`, `price.per: 10`, source quantity 10; physical coin pricing divides by `price.per`.
- Rest for the Night: `Hooks.callAll("pf2e.restForTheNight", actor)` runs on the initiating client.
- GM Screen Encounter Budget: Low threat has budget 60 and character adjustment 20 XP, consistent with GM Core p.75.
- Published equipment examples verify copied rule values and the artifact/prerequisite exclusions found during independent review.

## Remaining acceptance and limits

The revised branch has **not been installed or live-tested**. After authorized PR publication/test installation, rerun all three forge kinds and NPC/monster/encounter creation; test Rogue/Investigator/Fighter level-one feats, accelerated skill slots, worn gear and ammo, player rest, two item copies, failed charge updates, and macro deletion while another copy survives. Include a no-equipment/no-loot prompt and failed/cancelled loot reroll.

Existing companion macros contain saved command snapshots. Updating the module changes shared cleanup/rest hooks, but **does not rewrite old macro commands or old forged mechanics**. Test new companions for the command fixes; migrating old macros requires a separate deliberate operation. Same-client double clicks are guarded; simultaneous activations from different clients still lack an atomic Foundry compare-and-swap.

Activation dice/DCs are the module's existing GM Core benchmark policy, not a published magic-item balance table. Conditions still need manual duration adjudication. Rune prerequisite/exclusivity coverage, material-restricted armor runes, shields/ammunition forging, focus-spell acceptance, and unsupported PC classes remain at the documented support boundary.
