## 2. Game rules: ORC License

The module includes a small amount of Starfinder Second Edition game mechanics, mostly numbers transcribed from published tables:

- creature statistics by level (Building Creatures), treasure by level, character wealth and encounter budgets (*Starfinder GM Core*);
- spell slot progressions and the archetype spellcasting benefits (*Starfinder Player Core*);
- Technomancer spell slots and spell cache lists (*Starfinder Tech Core*).

Everything else (feats, spells, items, creatures, rule elements) is read at run time from the `sf2e` game system you install. This module does not ship it.
